# TimbrosaField Documentation

This directory contains maintained public documentation for TimbrosaField.

## Documents

- [User guide](user-guide.md): daily use of the application.
- [Development guide](development.md): local setup, tests, and code workflow.
- [Architecture notes](architecture.md): high-level structure and module roles.

## Documentation Rules

- Keep public docs short, current, and free of machine-local details.
- Keep private working notes under `notes/`, which is local-only and ignored.
- Publish only sanitized screenshots or media assets under `docs/`.
- Prefer updating an existing document over adding a new one for a narrow note.
